# 朗读（Windows 系统语音）

> 本文件由根 `AGENTS.md` 拆分而来；全局约束与文档索引见根 `AGENTS.md`。

## 是什么

EPUB 阅读窗口的朗读（TTS）：鼠标移到段落上会出现小喇叭，点它从该段开始按顺序把正文
读出来；工具栏的「朗读」从当前可见段落开始，播放中换成「暂停/继续」与「停止」。当前
朗读段高亮并自动滚到可视区，读到章末停止（跨章续读不做）。

朗读不写数据库、不改正文：高亮只切换一个可逆的 CSS 类，原文、笔记锚点、选区文本与
AI 引用都不受影响。

## 引擎：为什么先用 Windows 系统语音

`src/speech/` 是引擎边界（`SpeechEngine`：列出语音 + 把一段文字合成成 WAV 字节），
当前实现是 WinRT `SpeechSynthesizer`，播放用 `MediaPlayer`——两者都复用项目已有的
`windows` crate（只加 feature），**零新依赖、零模型、离线、首字延迟低于 100ms**。
本机已装的中文语音：Microsoft Huihui / Kangkang / Yaoyao。

为什么不上本地小模型或云端：

| 方案 | 代价 | 什么时候值得换 |
| --- | --- | --- |
| Windows 系统语音（现状） | 音质机械；音色取决于系统装了什么 | 默认选择 |
| 本地小模型（Piper 20–60MB / Kokoro-82M ≈300MB） | 需要 ONNX 运行时依赖（dll 20–50MB）+ 模型文件 + 首次加载 1–3 秒 | 更在意音质、能接受依赖与首次延迟 |
| 云端 TTS | 每次点击 0.3–2 秒网络往返 | 能接受联网与延迟、要最好的音质 |

引擎边界就是为这种替换准备的：换实现不需要动阅读窗口与页面脚本。

## 术语

- **朗读会话**：一次「从某段开始读到底」的过程。进程内**同时只允许一个**——系统语音与
  音频输出各只有一份。
- **音色**：一条系统语音（`SpeechVoice`），按 ID 持久化；空 ID 表示系统默认语音。
- **语速**：倍率，1.0 为正常。合法范围是 `SpeechRequest::RATE_MIN..RATE_MAX`；读取设置时
  钳制，手改坏的行不会让阅读窗口打不开。
- **预取**：会话在播放当前段时合成下一段（最多提前两段），段与段之间因此几乎无间隙。

## 不可破坏的约束

- **读什么**：跟随译文显示方式。页面按「该段有译文层就用译文层的文字，否则用正文文字」
  收集段落，所以「译文」与「双语」模式读译文、「原文」模式读原文；某段译文还没生成时
  读它当前显示的文字（所见即所读），不等待、不排队、不提示。
- **不读什么**：代码块与表格跳过（读出来没有意义），标题、段落、列表、引用正常读。
  脚注等其它结构暂未特殊处理：作为普通段落出现的脚注文字会被读出。
- **单会话**：开始新的朗读前，`ReadAloudRegistry` 登记的旧窗口先停；系统配置窗口的「试听」
  同样占用音频输出，会打断正在进行的朗读。
- **生命周期**：切换译文显示方式、切换章节、重新加载页面都会立即停止朗读并清除高亮。
  关闭窗口不必显式停止：会话保存在窗口状态里，随窗口释放收敛。
- **输入校验**：页面发来的段落列表按不可信输入处理——最多 2000 段、单段 8 KiB、合计
  512 KiB，且只接受**当前章页面**的请求。段落 id 只用于这一轮的对齐，不持久化。
- **高亮**：只切换 `ngy-read-aloud-active` 类，不动正文节点、文本与选区。朗读按钮是
  内联 SVG、没有文本节点，因此不进入块的 `textContent`，也不会被选区复制。
- **译文层不是朗读对象**：译文层会给每个块复制一份与源同名的文本元素（`<p>` 的译文还是
  `<p>`），候选块必须排除 `[data-ngy-translation]` 子树，否则同一段会被读两遍、段落索引
  也会整体后移。
- **触发方式不用单击段落**：正文的 `pointerup` 已被笔记占用（拖选后的选区工具栏与点击
  划线弹卡片），单击朗读会和它们打架。

## 设置

「系统配置」窗口的「朗读」段（音色、语速、试听），存全局 key
`speech.preferences.v1`，并列入 `AI_SETTINGS_KEYS` 的回滚清单。它是**应用级**设置：
不按书记忆，因此不需要任何删书清理。阅读窗口工具栏的朗读按钮旁有「设置」入口，直接
打开这一段；音色与语速保存后立即对新的朗读生效。

## 验证

- `cargo test --lib speech`：真实调用系统语音，验证语音列表、WAV 产物、未知音色报错、
  语速钳制与播放到结束（会出声一次，一秒以内）。
- `src/ui/reader/read_aloud.test.cjs` 是可选 DOM 门禁（Node + 已安装 Playwright，用法见
  `environment-and-commands.md`）；本机没有 Playwright 包时，可以用仓库里 headless
  Chromium 的 `--dump-dom` 跑探针页验证真实 DOM 行为（候选块、跳过代码/表格、译文跟随、
  高亮与清除）。
- 人工冒烟：三个中文音色各听一段、暂停与继续、点另一段切换、切章与切显示方式是否立即
  停止、双语与原文模式读的文字是否正确、朗读中滚动是否跟随、朗读时笔记与选区是否照常。
