# 分享导入把机器译文重新署名给接收方的翻译引擎

阅读端只显示 `model` 与执行身份（`translation_execution_identity`）都匹配当前设置的机器译文。朋友的端点与模型几乎不可能和你相同，所以照原样落库的分享译文会**一条都不显示**，分享也就失去意义。导入是用户明确发起的采纳行为，因此接收方把机器译文的 `model` 与执行身份改写成自己当前的翻译设置；整包只有一种目标语言、且接收方配置了默认译文语言时，连目标语言一起改写（这样朋友不必和你用同一个模型就能读到译文）。接收方没有配置翻译模型时保留发送方身份——那比伪造一个产出它的引擎诚实。

## Consequences

- 一段译文的署名不再等于产出它的模型；`manual_text`（读者手改的译文）本来就与模型无关，不受影响。
- 整包带多种目标语言时**不改写语言**：改写会让它们落到同一个 `(book, unit, block_id, target_language)` 上并互相覆盖，等于丢译文。
- 接收方换翻译引擎后，这些行会像自己翻的一样被 `adopt_execution_identity` 处理。
