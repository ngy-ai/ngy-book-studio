# 分享包携带规范化阅读投影，而不是原件

包是为了把一本书交给朋友，可以带原件（字节一致，导入方得到与发送方完全相同的书），也可以带应用自己的规范化 EPUB 投影。原件可能是几百 MB 的 PDF，而且应用内编辑过的书与原件早已不同，所以包里放的是 `reader_epub_bytes`——即当前阅读投影；导入走的就是普通 EPUB 导入（`FormatRegistry::import`），原件不随包走。

## Consequences

- 包体与原件大小解耦，编辑后的状态也能被分享；发送方导出的原件仍然可以在自己的库里单独导出。
- 接收方拿到的是一本由本应用规范化过的书：结构与文本一致，但 ID 与发送方不同（这也正是分区必须按序号定位的原因，见 ADR-0001）。
- PDF/DjVu 页面笔记在这条路上无法按页面规则复验，会随分区一起被跳过；只有在复用路径（见 ADR-0004）上才可用。
